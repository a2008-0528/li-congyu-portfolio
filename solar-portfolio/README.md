# 太阳系三维探索 · 个人简历作品

模型来自 ORBITAL_太阳系_V3.blend。浏览器加载 assets/solar-system-v3.glb，不依赖第三方CDN或私有站点。首页作品卡片指向本目录。

支持鼠标与触摸旋转缩放、天体聚焦、公转动画、时间轴、轨道开关、渲染图放大与模型下载。网页采用轻量材质与照明，和Blender离线渲染的体积大气、环阴影有所差异。

许可与来源：Three.js MIT（vendor/THREE-LICENSE.txt）；行星纹理 Solar System Scope，CC BY 4.0；NASA/Goddard SVS Deep Star Maps 2020，Gaia DR2: ESA/Gaia/DPAC，Ernie Wright (USRA)；轨道元素 NASA/JPL approximate positions。

全部行星大小和轨道距离采用展示比例，初始位置是示意排布，不对应现实日期的精确星历。
